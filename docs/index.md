# Python template repository

This project is a GitHub repository template for Python projects, with a focus on code quality, testing, and continuous integration. It includes a pre-configured GitHub Actions workflow for running tests and generating coverage reports.

This project is built with the following conventions and tools in mind:
- [Git Flow](https://nvie.com/posts/a-successful-git-branching-model/)
- [Semantic versioning](https://semver.org/)
- [Conventional Commits](https://www.conventionalcommits.org/)
- [git-cliff](https://git-cliff.org/) for generating changelogs
- [Ruff](https://docs.astral.sh/ruff/) for linting and formatting
- [ty](https://docs.astral.sh/ty/) for type checking
- [pytest](https://docs.pytest.org/en/stable/) for testing and coverage reporting
- [Sphinx](https://www.sphinx-doc.org/en/master/) for documentation
